CocoLoop Hub

CocoLoop Hub 是中文 AI Agent Skills 商店，收录 16 万+ Skills，提供 CLS 安全检查与国内镜像下载加速。

工具与定位

CocoLoop Hub（hub.cocoloop.cn）是中文 AI Agent Skills 商店，主打”更快更安全”。平台收录 160,701 个可用 Skills，支持 50+ 平台，通过 CLS 安全检查（CocoLoop Security 认证）与国内镜像下载加速降低获取门槛。精选 Top 50 榜单覆盖信息抓取、Agent 增强、技术开发、自媒体创作、产品与创业、知识/文件管理、理财炒股、赛博人类等分类。配套 Molili（墨立）安装器可快速完成 Skill 安装，社区站点为 www.cocoloop.cn。适合国内开发者、自媒体创作者与 AI Agent 玩家发现和使用现成技能。

版本与更新注意

Skills 由第三方开发者提供，执行前务必查看安全评级与权限声明，实际运行风险由用户自行承担。平台数据（Skills 数量、榜单）会持续更新，以 hub.cocoloop.cn 实时数据为准。

选型建议

国内用户优先选择：中文界面、国内镜像加速、CLS 安全认证是 CocoLoop Hub 相对国际市场的核心优势；需要开源可控或跨国团队的技能管理则搭配 SkillsMP、Skills.sh 等国际平台互补使用。
