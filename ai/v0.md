## 产品与定位

v0 是 Vercel 推出的 **React / Next.js UI 生成器**，用自然语言或截图生成基于 Tailwind CSS 的前端组件与页面。它擅长产出**视觉精美**的 React 界面——dashboard、landing page、组件库原型，是 Product Hunt vibe-coding 分类中公认的「最佳 React 组件生成器」。

v0 与 Vercel 生态深度绑定，生成代码可直接与 Next.js 项目、shadcn/ui 组件库配合，适合前端团队加速 UI 迭代。注意：**v0 不生成后端**，产出的是组件/页面而非完整产品。

## 功能速览

| 功能 | 说明 |
| --- | --- |
| 文本生成 UI | 自然语言描述 → React + Tailwind 组件 |
| 截图生成 | 上传设计稿/截图，还原为可编辑代码 |
| 设计系统支持 | 对齐 shadcn/ui 等设计系统与主题变量 |
| 迭代编辑 | 对话式持续修改组件 |
| 与 Vercel 集成 | 一键导入 Next.js 项目并部署 |

## 适用场景

| 场景 | 说明 |
| --- | --- |
| 前端原型 | 快速产出可交互的高保真界面原型 |
| Dashboard | 数据看板、管理后台前端 |
| Landing page | 营销落地页的 React 实现 |
| 组件库 | 与设计系统配套的组件探索 |

## 调用与兼容性

v0 是云端 SaaS（v0.dev），生成代码通过「Copy code」或项目集成导入。生成结果基于 Next.js/React + Tailwind，可平移到任何 React 工程。

## 选型建议

- 已有后端、只缺漂亮的前端 → v0 是最快路径。
- 需要连后端一起生成完整应用 → Lovable / Replit 更合适。
- 深度依赖 Vercel/Next.js 技术栈的团队 → 与 v0 配合度最高。
