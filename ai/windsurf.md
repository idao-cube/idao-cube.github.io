## 产品与定位

Windsurf 最初由 **Codeium（Exafunction Inc.）** 推出，是主打 Agent 模式的 AI 编程编辑器。2025 年 OpenAI 约 $3B 的收购告吹后，Windsurf 被 **Cognition（Devin 开发商）** 收购；**2026-06-02 通过 OTA 更名 Devin Desktop**，Windsurf 品牌正式退役——编辑器与订阅计划保持不变，本地 agent 更名 **Devin Local**，Devin Cloud agent 从 Pro 计划起可用。

现在它是 **Devin 家族的 IDE 前端**：既能作为 Cursor 的平替（Pro $20/月），也能无缝接入 Devin 的云端自主 agent。Cascade 助手已于 2026-07-01 退役。

## 功能速览

| 功能 | 说明 |
| --- | --- |
| Agent 模式 | 深度 AI 协作，自动执行多步任务 |
| Devin Local | 更名后的本地 agent（原 Cascade） |
| Devin Cloud | 云端自主 agent，Pro 起可用 |
| SWE-1.5 模型 | Cognition 自研，号称比 Claude Sonnet 4.5 快 13x |
| Codemaps | 代码库结构地图，提升上下文理解 |
| 上下文感知 | 理解整个代码库 |
| 多模型支持 | 灵活切换 AI 模型 |

## 版本与更新注意

- **2026-06-02**：OTA 更名 Devin Desktop，品牌切换，功能不变。
- **2026-07-01**：Cascade 助手退役，本地 agent 统一为 Devin Local。
- 2026-03：Pro 涨价至 $20/月，计费改配额制。

## 选型建议

- 想要 Cursor 级体验但预算有限的开发者 → Windsurf/Devin Desktop（Pro $20/月）。
- 需要云端自主 agent 的团队 → Pro 起即可用 Devin Cloud，与 Devin 生态打通。
- 老 Codeium 用户 → 编辑器不变，可平滑过渡，功能只增不减。
