## 产品与定位

腾讯云代码助手 Codebuddy，深度集成 VS Code 和 JetBrains IDE。支持多文件修改、语音输入、全双工语音交互和代码库理解，适合需要深度 IDE 集成的开发者。

## 功能速览

| 功能 | 说明 |
| --- | --- |
| 多文件编辑 | 单次提示修改多个文件 |
| 语音交互 | 语音输入指令，AI 语音回复 |
| 代码库理解 | 扫描仓库生成向量数据库 |
| Web 参考集成 | 从网页获取文档并实现 |
| 向量检索 | 智能选择相关文件 |
| 差异化补丁 | 统一的 Diff 格式确认后应用 |

## 常用场景

| 场景 | 功能 |
| --- | --- |
| 多文件修改 | 一次对话修改多个文件 |
| 语音编程 | 语音输入需求 |
| 代码理解 | 询问不熟悉的代码 |
| 文档实现 | 从网页获取文档并编写代码 |
| 代码审查 | 审查代码问题和建议 |

## 调用与兼容性

```bash
# VS Code 扩展安装
# 打开 VS Code -> 扩展 -> 搜索 "Codebuddy"

# JetBrains 插件安装
# 打开 JetBrains IDE -> Plugins -> 搜索 "Codebuddy"
```

## 版本与更新注意

提供免费版和付费版，部分高级模型需要付费。支持最新 IDE 版本。

## 选型建议

腾讯生态用户、需要语音交互首选 Codebuddy；与 VS Code/JetBrains 深度集成，上手成本低。
