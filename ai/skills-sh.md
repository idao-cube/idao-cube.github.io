## 平台与定位

Skills.sh 是 Open Agent Skills 生态的官方平台（Vercel 维护），聚合了来自 Vercel、Microsoft、Anthropic、Supabase 等机构的 57,000+ 技能包。通过 `npx skills add <owner/repo>` 一条命令即可为 Cursor、Claude Code、OpenCode、Copilot 等 70+ 工具安装技能，是技能分发的事实枢纽。

## 安装方式

| 方式 | 命令 |
| --- | --- |
| 安装技能 | `npx skills add vercel-labs/skills` |
| 安装指定技能 | `npx skills add obra/superpowers` |
| 搜索技能 | 访问 [skills.sh](https://skills.sh/) 搜索 |
| 查看趋势 | 查看 [Trending](https://skills.sh/trending) 榜单 |

## 选型建议

日常开发先安装 find-skills（自动发现技能）；框架项目选对应 best-practices；云项目选 azure/firebase 系列；营销站点选 seo + copywriting；热门社区库（superpowers/mattpocock）均可通过 skills CLI 直接接入。
