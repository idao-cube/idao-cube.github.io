## 产品与定位

Replit 创立于 2016 年，是**云端浏览器开发环境**的鼻祖：IDE、数据库、托管、部署全部一体，无需本地安装、零配置即可开发。内置 AI Agent（目前为 Agent 4），可以对话式构建、调试、部署应用。

它同时是 vibe-coding 榜单中公认「**最适合学习**」的平台——非程序员、学生、内部工具团队可以无门槛上手。缺点也明显：冷启动 10-30 秒、托管不适合高并发生产、存在厂商锁定风险。

## 功能速览

| 功能 | 说明 |
| --- | --- |
| 云端 IDE | 浏览器内完整开发环境，多语言支持 |
| AI Agent | Agent 4 对话式编码、自动补全、调试 |
| 一键部署 | 内置托管与域名，写完成直接上线 |
| 数据库 | 内置 KV/Postgres 等数据存储 |
| 实时协作 | 多人同屏编辑（类似 Google Docs） |
| 模板市场 | 大量预置项目模板一键创建 |

## 适用场景

| 场景 | 说明 |
| --- | --- |
| 学习编程 | 零配置，最适合入门与教学 |
| 快速原型 | 内部工具、Demo、黑客松作品 |
| 团队协作 | 多人实时共同开发 |
| 小规模部署 | 低流量应用直接托管 |

## 调用与兼容性

Replit 是纯云端服务，浏览器访问 replit.com 即可，无需本地工具链。可通过 Replit Agent API / SDK 将 AI 能力接入自己的工作流。

## 版本与更新注意

- 定价：免费层；Core $25/月；Pro $95/月（更高算力与隐私部署）。
- 冷启动 10-30 秒、非生产级托管：高流量或对延迟敏感的应用建议迁移到专业托管。

## 选型建议

- 学生、非程序员、想快速验证想法 → Replit 上手门槛最低。
- 需要生产级托管与 CI/CD → 生成的代码导出后用专业平台部署。
- 深度代码库理解、多仓库重构 → 优先考虑 Cursor / Claude Code。
