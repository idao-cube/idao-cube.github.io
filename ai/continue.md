## 产品与定位

开源的 AI 编程助手插件，深度集成 VS Code 和 JetBrains IDE。支持多模型、代码库上下文理解与自定义配置，适合 VS Code 重度用户。

## 功能速览

| 功能 | 说明 |
| --- | --- |
| 代码补全 | 上下文感知的智能补全 |
| 对话界面 | IDE 内聊天提问 |
| 代码库感知 | 理解整个项目上下文 |
| 多模型支持 | Claude、GPT-4、CodeLlama 等 |
| 自定义配置 | 本地模型和 API 配置 |
| MCP 扩展 | 连接外部工具和服务 |

## 常用场景

| 场景 | 功能 |
| --- | --- |
| 代码生成 | 根据上下文生成代码 |
| 代码解释 | 解释函数和逻辑 |
| Bug 修复 | 分析并修复问题 |
| 文档生成 | 生成代码注释和文档 |
| 重构建议 | 提出改进方案 |

## 调用与兼容性

```bash
# 安装 VS Code 扩展
# 然后配置 config.json
{
  "models": [
    {
      "model": "claude-sonnet-4-6",

  ]

```
