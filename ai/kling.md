## 产品与定位

快手可灵 AI 是国产领先的视频生成模型，支持最长 2 分钟视频、口型同步与 4K 高清输出。Kling v3 版本支持静态图片直接生成原生 4K 视频，无需后期升频。与快手生态深度集成，适合短视频创作者和电商内容制作。

## 功能速览

| 功能 | 说明 |
| --- | --- |
| 文生视频 | 输入文字描述生成视频片段 |
| 图生视频 | 上传图片生成动态视频 |
| 原生 4K | Kling v3 直接输出 3840×2160 无需升频 |
| 长视频支持 | 最长 2 分钟，适合复杂叙事 |
| 口型同步 | 视频生成同步匹配音效与台词口型 |
| 运镜控制 | 支持镜头运动、景别切换等专业控制 |

## 常用参数

| 参数 | 作用 | 常见建议 |
| --- | --- | --- |
| `prompt` | 视频描述词 | 详细描述场景、动作、风格效果更好 |
| `duration` | 视频时长 | 短片 5-15 秒，长视频最长 2 分钟 |
| `resolution` | 输出分辨率 | 最高支持 4K |
| `aspect_ratio` | 画幅比例 | 9:16 竖屏/16:9 横屏/1:1 方屏 |
| `negative_prompt` | 反向描述 | 排除不需要的元素 |
| `seed` | 随机种子 | 固定种子可复现相似结果 |

## 调用与兼容性

```bash
# API 调用示例（通过快手开放平台）
curl -X POST https://api.klingai.com/v1/video/generate \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "prompt": "一只猫在草地上奔跑，阳光明媚",
    "duration": 10,
    "resolution": "1080p",
    "aspect_ratio": "16:9"
  }'
```

## 版本与更新注意

Kling v3 版本支持原生 4K 输出（最高 10 秒），v2.5 版本保持 1080p 可用。建议关注官方发布获取最新能力。

## 选型建议

快手/短视频创作者首选；长视频需求、电商广告、企业宣传片优先评估可灵；中文场景优化成熟。
