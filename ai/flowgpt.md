## 工具与定位

FlowGPT 是全球最大的 AI 提示词社区，汇聚数百万用户分享的提示词模板，覆盖 ChatGPT、Midjourney、Stable Diffusion、Claude 等主流模型。支持在线运行、一键复制和效果评分，是寻找灵感与最佳实践的首选平台。

## 场景覆盖

| 场景 | 热门提示词类型 |
| --- | --- |
| 编程开发 | Code Review、Debug、算法解释、单元测试 |
| 内容创作 | 博客写作、营销文案、社交媒体、剧本 |
| 设计创意 | Midjourney 风格、Logo 设计、UI 描述 |
| 数据分析 | SQL 生成、可视化建议、报告撰写 |
| 学习教育 | 知识点解释、练习题生成、语言学习 |
