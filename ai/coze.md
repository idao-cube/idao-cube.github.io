## 产品与定位

适合无需编程即可快速搭建 AI 智能体和工作流的平台，支持多模型调用、插件扩展、知识库管理和多渠道发布。国内版（coze.cn）和国际版（coze.com）计费模式不同，可按需选择。

## 功能速览

| 功能 | 说明 |
| --- | --- |
| 智能体编排 | 可视化工作流设计，无需代码 |
| 多模型支持 | 豆包、DeepSeek、GPT、Claude 等主流模型 |
| 插件生态 | 丰富的插件扩展和第三方 API 接入 |
| 知识库 | 支持 RAG 文档检索和私有知识管理 |
| 多渠道发布 | 微信公众号、飞书、企业微信等 |
| 工作流节点 | 条件分支、代码片段、HTTP 请求等 |

## 常用参数

| 参数 | 作用 | 常见建议 |
| --- | --- | --- |
| `model` | 选择模型 | 根据任务复杂度选择对应模型 |
| `temperature` | 控制随机性 | 精确任务低温，创意任务高温 |
| `max_tokens` | 输出限制 | 控制响应长度和成本 |
| `system_prompt` | 系统提示 | 定义智能体角色和能力边界 |
| `workflow` | 工作流配置 | 复杂任务使用工作流节点编排 |

## 调用与兼容性

国内版支持豆包等国内模型，国际版支持 GPT-4o、Claude 等海外模型。可通过 API 调用或平台内置插件发布智能体。

## 版本与更新注意

扣子 2.5 版本更新后功能大幅增强，建议关注官方教程和更新日志获取最新能力。

## 选型建议

需要快速验证 AI 智能体概念、非技术团队构建自动化流程首选扣子；复杂企业场景可结合 API 封装实现深度定制。
