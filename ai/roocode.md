## 产品与定位

开源 AI 编程助手（ Roo Code，前身 Roo Cline），专注稳定性和可预测性。不是追求最快最强，而是追求最可靠，尤其适合复杂多文件修改和关键任务。

## 功能速览

| 功能 | 说明 |
| --- | --- |
| 计划阶段 | 修改前先制定计划 |
| 依赖分析 | 理解修改顺序和依赖关系 |
| 验证步骤 | 防止回归的验证机制 |
| 保守策略 | 正确性优先于速度 |
| 多文件修改 | 一次对话修改多个文件 |
| 开源免费 | 社区驱动，持续更新 |

## 设计理念

与其他 Agent 追求速度和功能广度不同，Roo Code 追求：
- 复杂修改可预测
- 不"震荡"（不做出冲突修改）
- 关键任务的可靠性

## 与 Cursor 对比

| 特性 | Roo Code | Cursor |
| --- | --- | --- |
| 可靠性 | 高 | 中 |
| 速度 | 中 | 快 |
| 功能广度 | 中 | 高 |
| 适合场景 | 复杂重构 | 日常编码 |
| 开源 | 是 | 否 |

## 版本与更新注意

2026 年 4 月宣布停止 VS Code 扩展，转向云端 Agent 服务（Roomote）。现有用户可继续使用至 2026 年 5 月。

## 选型建议

复杂重构、遗留代码迁移、架构变更等关键任务首选 Roo Code；日常编码可用 Cursor 互补。
