## 产品与定位

Black Forest Labs（原 Stable Diffusion 团队）推出的图像生成模型家族，已发展为涵盖生成、编辑、放大、修复的完整生态。开源版本和商业版本并行。

## 功能速览

| 功能 | 说明 |
| --- | --- |
| 文生图 | 多版本覆盖不同质量/速度需求 |
| 图生图 | 图像到图像转换 |
| 图像编辑 | 7 种编辑模型（遮罩/外绘） |
| 图像放大 | Flux Creative Upscale |
| 图像修复 | 6 种修复模型 |
| 无审查 | 部分版本无内容过滤 |

## 模型层级

| 模型 | 价格 | 适用场景 |
| --- | --- | --- |
| Flux Schnell | 免费 | 快速原型 |
| Flux 2 Klein | 低 | 日常使用 |
| Flux 2 Klein 4B | 免费 | 本地轻量运行 |
| Flux 1.1 Pro | 中 | 商业生产 |
| Flux 2 Pro | 高 | 高质量商业 |
| Flux 2 Max | 最高 | 旗舰品质 |

## 调用方式

| 方式 | 说明 |
| --- | --- |
| Upsampler | 免费使用，21 个模型 |

| 官方 Playground | flux.ai/playground |

## 版本与更新注意

模型持续迭代，2026 年发布 Flux 2 系列。建议关注官方更新获取最新能力。

## 选型建议

需要开源方案、灵活部署首选 FLUX；商业生产根据质量要求选择 Pro/Max 版本。
