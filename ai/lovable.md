## 产品与定位

Lovable 自称「The world's first AI Fullstack Engineer」（其前身为 GPT Engineer）。它通过聊天对话生成**真实可运行的全栈 Web 应用**，直接产出 React / TypeScript / Tailwind 代码，而非原型稿或静态页面。

与纯前端生成器（如 v0）不同，Lovable 内置 **Lovable Cloud 后端**，包含用户认证与数据持久化，一个 prompt 就能得到「能登录、能存数据」的完整应用。它是 Product Hunt vibe-coding 分类的头部产品，也是公认的**非开发者首选**——设计师、indie hacker、代理机构用它快速交付 MVP。

## 功能速览

| 功能 | 说明 |
| --- | --- |
| 全栈生成 | 聊天生成真实 React/TypeScript/Tailwind 代码，含前端与后端 |
| Lovable Cloud | 内置后端：用户认证（auth）+ 数据持久化，开箱即用 |
| 实时协作 | 多人实时共同编辑，协作者数量无限制 |
| Agentic 模式 | 多步自主编辑，按任务链连续修改多个文件 |
| 并行 AI 子代理 | 2026 年 5 月上线，多个子代理并行处理独立任务 |
| AI 连接器 | 接入 Perplexity、ElevenLabs、Firecrawl、Miro 等第三方服务 |
| 可视化编辑 | 可视化 CSS 编辑、主题系统、内置分析、域名购买 |

## 调用与兼容性

Lovable 是云端 SaaS，无需本地安装。生成的应用可一键部署，代码可导出到本地仓库（GitHub 集成）继续用其他工具维护。

## 版本与更新注意

- 2026 年 5 月上线并行 AI 子代理能力。
- 定价：免费层（有限消息额度）+ Pro $25/月。

> ⚠️ 注意：快速 MVP ≠ 可维护产品。Lovable 生成的后端深度有限，业务扩展、复杂权限、性能优化时仍需开发者介入加固。

## 选型建议

- 想用自然语言快速构建**全栈**应用、且自己不动手写代码 → Lovable。
- 只要前端 UI 组件、已有后端 → 优先考虑 v0。
- 需要深度定制、长期演进的生产系统 → 仍建议以 Cursor / Claude Code 等编码工具为主，Lovable 作原型加速器。
