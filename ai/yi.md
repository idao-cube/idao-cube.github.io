## 模型与定位

零一万物（01.AI）由李开复创立。旗舰开源模型 **Yi-Lightning**（2024-10-16 发布）：100B 参数 MoE 架构，LMSYS Chatbot Arena 世界第六、中国第一（1287 分），内置 RAISE 安全框架。2026-02-05 发布 **万智 2.5 企业级多智能体平台**，开启 2026 年"硅基团队"上岗元年——公司重心已从通用模型 API 转向企业级多智能体应用。适合中文问答、内容创作、开发助手与企业级多智能体/工作流构建。

## 参数速览

| 项目 | 说明 |
| --- | --- |
| 输入模态 | 文本为主（Yi-Lightning），按型号扩展多模态 |
| 输出能力 | 文本、结构化内容、函数调用 |
| 推理模式 | 通用推理 + 企业多智能体编排 |
| 典型模型名 | Yi-Lightning、Yi-1.5 系列（开源）、万智 2.5（企业多智能体） |
| 上下文窗口 | 不同模型上下文能力不同（Yi-Lightning 200K） |
| 参数量 | 100B MoE（Yi-Lightning） |

## 常用请求参数

| 参数 | 作用 | 常见建议 |
| --- | --- | --- |
| `model` | 指定模型档位 | 建议为不同业务定义默认模型 |
| `temperature` | 控制创造性 | 摘要和问答建议低温 |
| `top_p` | 采样控制 | 对稳定性敏感时调低 |
| `max_tokens` | 输出长度限制 | 防止长输出增加时延 |
| `tools` | 工具调用 | 自动化任务建议启用 |
| `stream` | 流式响应 | 聊天产品建议开启 |

## 调用与兼容性

平台 API（platform.lingyiwanwu.com，OpenAI 兼容）便于在业务后端统一管理鉴权、配额和日志；开源权重（HuggingFace）可自部署。企业多智能体方案通过万智平台交付。

## 版本与下线注意

Yi-Lightning 为 2024 年旗舰，公司现已转向企业多智能体（万智 2.5），通用模型 API 迭代放缓；建议关注平台公告确认模型可用性与下线计划。

## 选型建议

如果主要目标是中文体验、落地效率与成本平衡，Yi 系列值得纳入对比评测；若需要开箱即用的多智能体团队（规划/执行/审查分工），可直接评估万智 2.5 企业方案。
