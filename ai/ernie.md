## 模型与定位

文心大模型（ERNIE）由百度研发，历经多代迭代。**文心 5.0**（2026-01-22 发布）为新一代旗舰：2.4 万亿参数、原生全模态统一建模，文本/图像/音频/视频多模态理解与生成一体。**文心 5.1**（2026-05-09 发布）进一步压缩总参至约 1/3、激活约 1/2，预训练成本仅为此前的 6%，采用分离式全异步强化学习，在 LMSYS Arena 搜索榜全球第四、国内第一（1223 分）。适合中文业务场景、知识问答、智能客服、多模态内容生成与企业应用集成。

## 参数速览

| 项目 | 说明 |
| --- | --- |
| 输入模态 | 文本、图像、音频、视频（原生全模态） |
| 输出能力 | 文本、结构化输出、工具调用、图像/音频/视频生成 |
| 推理模式 | ERNIE-5.0-Thinking 系列提供深度推理，4.5-Turbo 提供高速档 |
| 典型模型名 | ernie-5.1、ernie-5.0、ERNIE-5.0-Thinking-Preview/Latest、ERNIE-4.5-Turbo-128K、ERNIE X1.1 |
| 上下文窗口 | ERNIE-5.x 支持 128K |

## 常用请求参数

| 参数 | 作用 | 常见建议 |
| --- | --- | --- |
| `model` | 指定模型档位 | 线上建议固定可追踪版本（如 ernie-5.1） |
| `temperature` | 输出多样性控制 | 客服和问答场景建议低温 |
| `top_p` | 采样控制 | 对稳定性敏感场景可降低 |
| `max_output_tokens` | 输出长度限制 | 建议结合产品字数约束 |
| `response_format` | 响应格式约束 | 业务系统建议结构化输出 |
| `stream` | 流式传输 | 交互场景建议启用 |

## 调用与兼容性

通过文心千帆（百度智能云千帆大模型平台）API 接入，与百度云生态服务联动，适合企业级权限和资源管理。模型体验入口为 ernie.baidu.com。

## 版本与下线注意

ERNIE 系列存在版本迁移周期（如 4.x → 5.x），部分模型会进入维护或下线，建议关注千帆平台公告并提前完成回归测试；Thinking 系列为预览/最新标签，生产建议固定版本号。

## 选型建议

中文理解与企业落地并重时优先评估文心；追求速度与成本先用 ERNIE-4.5-Turbo 验证流程，再切换 ERNIE-5.x 旗舰提升效果；多模态场景直接评估文心 5.0/5.1 的全模态统一能力。
