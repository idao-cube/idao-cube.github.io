## 工具与定位

PromptPerfect 是专注提示词优化的 AI 工具，一键将简陋提示词改写为高质量指令。支持 GPT、Claude、Midjourney、Stable Diffusion 等多模型适配，内置评分系统，可迭代改进直到满意为止。

## 核心功能

| 功能 | 说明 |
| --- | --- |
| 一键优化 | 输入原始提示词，自动生成优化版本 |
| 多模型适配 | 针对 GPT、Claude、Midjourney 等调整格式 |
| 评分系统 | 对提示词质量打分，量化改进效果 |
| 迭代改进 | 多轮优化，逐步提升提示词质量 |
| 历史记录 | 保存所有版本，对比选择最佳 |

## 优化维度

| 维度 | 说明 |
| --- | --- |
| 清晰度 | 消除歧义，明确任务目标 |
| 上下文 | 补充背景信息，提升准确性 |
| 格式约束 | 指定输出格式（JSON、Markdown 等） |
| 示例引导 | 添加 Few-shot 示例 |
| 角色设定 | 赋予模型特定角色与视角 |
