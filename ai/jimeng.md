## 产品与定位

即梦AI是字节跳动推出的AI创作平台，支持AI绘画和AIGC视频生成。适合创意工作者、内容创作者和营销团队快速生成高质量图片和视频内容。

## 功能速览

| 功能 | 说明 |
| --- | --- |
| AI绘画 | 输入文字描述即可生成图片，支持风格选择、主体保持等高级功能 |
| AI视频生成 | 输入文案或图片，快速生成视频片段，支持多种风格和时长 |
| 图片创意改造 | 对现有图片进行风格迁移、背景替换、姿势保持等操作 |
| 社区灵感 | 提供创作灵感社区，可浏览和参考其他用户作品 |

## 常用参数

| 参数 | 作用 | 常见建议 |
| --- | --- | --- |
| `prompt` | 生成描述词 | 描述越详细效果越好，中英文均可 |
| `aspect_ratio` | 画幅比例 | 常用 16:9、9:16、1:1 等 |
| `style` | 风格选择 | 根据场景选择对应风格模板 |
| `negative_prompt` | 反向描述 | 排除不需要的元素，提升生成质量 |
| `image_count` | 生成数量 | 批量生成便于挑选最优结果 |

## 调用与兼容性

支持网页端交互操作，适合快速创意验证。也可通过 API 接入实现自动化内容生产流水线。

## 版本与更新注意

模型和风格持续迭代，建议关注平台更新日志获取新功能和能力提升信息。

## 选型建议

需要快速生成营销图片和短视频素材时可优先使用；复杂商业项目建议先在小批量场景验证效果后再扩大应用。
