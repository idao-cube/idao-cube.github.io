## 产品与定位

Cursor 3（2026年4月发布）是全新的 Agent 优先编程工作区，将 IDE 从代码编辑器转型为 AI Agent 舰队控制中心。1M+ 日活用户，$50B 估值，支持 Composer 2 自研编程模型。适合个人开发者和团队协作。

## 功能速览

| 功能 | 说明 |
| --- | --- |
| Agent 优先界面 | 多 AI Agent 并行执行，支持本地/云端切换 |
| 多仓库支持 | 跨仓库并行工作，统一管理 |
| 云端无缝衔接 | 机器离线时 Agent 切换到云端继续执行 |
| 内置浏览器 | 本地网站交互测试的集成浏览器 |
| Composer 2 | 自研前沿编程模型，高使用限额 |
| MCP 支持 | 扩展工具生态连接外部服务 |
| 插件市场 | 扩展 Agent 能力的插件系统 |

## 常用操作模式

| 模式 | 用途 |
| --- | --- |
| Agent 模式 | 直接编写代码，自动化修改 |
| Plan 模式 | 规划架构和大型重构 |
| Ask 模式 | 讨论代码，无修改意图 |
| Debug 模式 | 聚焦 Bug 修复，日志分析 |
