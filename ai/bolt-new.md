## 产品与定位

StackBlitz 推出的 AI 编程助手，能在浏览器中生成、运行和部署完整全栈项目。支持前端和后端代码生成，一键部署到生产环境。2026 年已迭代至 **Bolt 2.0**，是「最快出 demo」的 vibe-coding 工具，适合原型与演示。

> ⚠️ 安全提示：2026 年第三方测评发现，Bolt 生成的应用可能出现**硬编码 API key 位于前端 JS、仅客户端认证**等安全隐患。生产上线前必须人工审查密钥管理与认证逻辑。

## 功能速览

| 功能 | 说明 |
| --- | --- |
| AI 生成代码 | 描述需求生成完整项目 |
| 浏览器运行 | 内置开发服务器，无需本地环境 |
| 一键部署 | 直接部署到生产环境 |
| 全栈支持 | 前端 + 后端代码生成 |
| 项目模板 | 多种技术栈模板可选 |
| 在线编辑 | 可视化修改生成代码 |

## 版本与更新注意

- 已发布 Bolt 2.0，持续迭代中。
- 定价：免费层（有限用量）+ Pro $25/月（更高额度与优先能力）。WebContainer 技术实现浏览器内运行 Node.js。
- 生产上线前务必审查安全项（密钥、认证、权限）。

## 选型建议

快速原型、演示项目、无需本地环境首选 Bolt.new；复杂项目可导出本地继续开发。
