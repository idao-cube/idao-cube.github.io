## 模型与定位

适合重视模型性能、可部署灵活性与欧洲生态合规需求的团队。

## 参数速览

| 项目 | 说明 |
| --- | --- |
| 输入模态 | 文本为主，按系列支持多模态 |
| 输出能力 | 文本、结构化输出、工具调用 |
| 推理模式 | 提供从轻量到高质量的多档位模型 |
| 典型模型名 | `mistral-large-3`、`mistral-small-2603`、`mistral-small-4` |
| 上下文窗口 | 256K（Mistral Small 4），依型号与版本差异化提供 |

## 常用请求参数

| 参数 | 作用 | 常见建议 |
| --- | --- | --- |
| `model` | 模型选择 | 高难任务选高质量档 |
| `temperature` | 控制随机性 | 代码和抽取建议低温 |
| `top_p` | 采样范围 | 与温度联合微调 |
| `max_tokens` | 输出上限 | 防止超长输出 |
| `response_format` | 格式约束 | 系统集成建议 JSON |
| `stream` | 流式传输 | 交互场景建议开启 |

## 调用与兼容性

支持官方 API 与多种框架接入，也常用于开源与私有化混合方案。

## 版本与下线注意

建议区分开源自部署版本与托管 API 版本，避免能力预期不一致。

## 选型建议

需要兼顾性能、开放性和部署策略灵活度时，Mistral 是非常稳妥的候选。
