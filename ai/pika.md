## 产品与定位

高性价比 AI 视频平台，以慷慨的免费额度著称（每日 30 credits）。Pika 2.5 版本支持最长 25 秒视频，适合短视频创作和快速迭代。

## 功能速览

| 功能 | 说明 |
| --- | --- |
| 文生视频 | 文字描述生成视频片段 |
| 图生视频 | 图像转动态视频 |
| Pikaffects | 视觉效果变换（融化、爆炸、蛋糕化等） |
| Pikadditions | 向视频插入新对象或角色 |
| Pikaframes | 首尾帧过渡，最长 25 秒 |
| 场景扩展 | 长视频叙事支持 |
| 音效生成 | 自动匹配画面动作的音效 |
