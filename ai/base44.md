## 产品与定位

Base44 是**纯自然语言 AI 应用构建器**：单条 prompt 生成完整应用——前端 + 后端 + 数据库 + 认证 + 托管 + 第三方集成，全程无需代码。它被多个 2025-2026 vibe-coding 榜单评为 **#1**。

**2025-06-18 被 Wix 收购**（约 $80M 初始 + 里程碑 earnout，累计已超过 $150M）。2026-06-29 发布自研 **Base 1 模型**，专为构建 Web 应用训练，进一步降低推理成本。运营数据亮眼：6 个月执行 50 亿+ automations，声称 0.07% 错误率，ARR 约 $150M（2026-05）。

## 功能速览

| 功能 | 说明 |
| --- | --- |

## 版本与更新注意

> ⚠️ 安全提示：Wix 年报提及 vibe-coding 生成的应用可能引入未检测漏洞（Base44 曾有认证绕过漏洞被披露）。生产上线前务必做安全审计。

## 选型建议

- 非开发者、要最快生成带数据库的应用 → Base44 是榜单第一梯队。
- 在意安全合规的企业 → 生成后必须安全审查，或改用可控的编码 agent。
- 已有技术团队 → Lovable / Cursor 提供更强的定制能力。
