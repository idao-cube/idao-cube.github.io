## 产品与定位

全球市场份额最高的 AI 图像生成工具（26.8%），通过 Discord 和 Web 界面提供服务。V8 Alpha 于 2026 年 3 月发布，带来 5 倍生成速度提升和原生 2K 输出。

## 功能速览

| 功能 | 说明 |
| --- | --- |
| 文生图 | 输入描述生成高质量图像 |
| V8 模型 | 2026 年 3 月发布的最新版本 |
| Draft Mode | 10 倍速草稿模式 |
| 语音提示 | 支持语音输入指令 |
| 图生视频 | 静态图像转视频动画 |
| Web 编辑器 | 全新网页编辑器取代纯 Discord 模式 |
| Stealth 模式 | Pro 版独有，完全私密生成 |
| Animate 按钮 | 2026 新增，一键转视频 |

## 常用参数

| 参数 | 作用 | 示例 |
| --- | --- | --- |
| `--aspect` | 画幅比例 | `--ar 16:9`、`--ar 1:1` |
| `--stylize` | 风格化强度 | `--s 100` 到 `--s 1000` |
| `--hd` | 高清模式 | V8 原生 2K 输出 |
| `--q` | 质量等级 | `--q 2` 到 `--q 4` |
| `--v` | 模型版本 | `--v 8`、`--v 7` |
| `--style` | 风格预设 | `--style raw` 写实风格 |

## 调用与兼容性
