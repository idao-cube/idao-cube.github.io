## 产品与定位

站式 AI 创作平台，整合多个行业领先的视频生成模型，支持文生视频、图生视频与 4K/60fps 高清输出。免费额度充足，适合创作者快速验证创意。

## 功能速览

| 功能 | 说明 |
| --- | --- |
| 文生图 | 文字描述生成高质量图片 |
| 图生视频 | 图片转动态视频，支持首尾帧控制 |
| 文生视频 | 文字描述直接生成视频片段 |
| 多模型切换 | 集成多个视频生成模型，可对比效果 |
| 4K 输出 | 支持 4K 分辨率和 60fps 高帧率 |
| 音频支持 | 支持视频配音和背景音乐 |

## 常用参数

| 参数 | 作用 | 常见建议 |
| --- | --- | --- |
| `prompt` | 创作描述 | 中英文均可，描述越详细效果越好 |
| `model` | 选择模型 | 不同模型风格和质量各异 |
| `width/height` | 画幅尺寸 | 根据使用场景选择合适比例 |
| `steps` | 生成步数 | 越多越精细但耗时更长 |
| `cfg_scale` | 引导强度 | 控制与提示词匹配度 |
| `seed` | 随机种子 | 固定可复现相似结果 |
