## 模型与定位

DALL·E 系列是 OpenAI 的旗舰图像生成模型，擅长将复杂的自然语言描述转化为高质量图像。DALL·E 3 与 ChatGPT 深度集成，支持多轮对话式优化，在文字渲染、细节还原和风格多样性上表现突出。

## 参数速览

| 模型 | 分辨率 | 特性 | 访问方式 |
| --- | --- | --- | --- |
| DALL·E 2 | 1024×1024 | 基础生成、编辑、变体 | OpenAI API |
| DALL·E 3 | 1024×1792 / 1792×1024 | 精准语义理解、文字渲染 | ChatGPT / API |

## 核心能力

| 功能 | 说明 |
| --- | --- |
| 对话式生成 | 与 ChatGPT 多轮对话，逐步优化图像 |
| 文字渲染 | 准确生成图像中的英文文字内容 |
| 细节控制 | 支持高度、宽比、风格等参数调整 |
| 图像编辑 | DALL·E 2 支持局部修复（inpainting） |

## 平台接入

| 平台 | 说明 |
| --- | --- |
| [ChatGPT](https://chat.openai.com/) | 直接对话生成（Plus 用户） |
| [OpenAI API](https://platform.openai.com/) | 开发者接入 |
| [Bing Image Creator](https://www.bing.com/images/create) | 免费使用 DALL·E 2/3（微软） |

## 选型建议

ChatGPT Plus 用户直接用 DALL·E 3；开发者接入选 API；免费体验可试 Bing Image Creator。
