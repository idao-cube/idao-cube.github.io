## 产品与定位

字节跳动推出的 Agentic AI IDE，定位为"10x AI Engineer"。不是简单的代码补全工具，而是能够自主执行任务的智能开发环境，将提示词转换为结构化工作流并自动执行。

## 功能速览

| 功能 | 说明 |
| --- | --- |
| Agent 任务执行 | 自主执行多步骤开发任务 |
| 任务分解引擎 | 内置任务拆解和依赖分析 |
| 上下文感知 | 理解项目代码结构和依赖 |
| 自动化调试 | 自动 Bug 修复和代码重构 |
| 自然语言开发 | 用自然语言描述需求即可生成代码 |
| 工作流自动化 | 减少手动编码，提升效率 |

## 与 Cursor 对比

| 特性 | Trae AI | Cursor |
| --- | --- | --- |
| 核心方式 | Agentic（执行任务） | Assistive（辅助编码） |
| 任务执行 | 自主执行 | 手动确认 |
| 自动化程度 | 高 | 中 |
| 学习曲线 | 中等 | 简单 |
| 适合场景 | 自动化和速度 | 代码补全和编辑 |
