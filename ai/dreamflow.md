## 产品与定位

Dreamflow 是 FlutterFlow 团队打造的 AI 可视化开发平台，专注于**生产级移动应用**：自然语言描述即可生成屏幕与功能，结合可视化画布与原始代码编辑，一键部署到 App Store / Play Store。它弥补了通用 vibe coding 工具"只能做 Web"的短板，面向开发者、独立创始人、产品团队——既要 AI 加速又要能真正上架的移动端团队。

## 功能速览

| 功能 | 说明 |
| --- | --- |
| AI 生成屏幕与功能 | 提示词描述需求，AI 生成 Flutter 界面与业务逻辑 |
| 可视化 + 代码双编辑 | 画布拖拽与原始代码编辑并存，产出可维护 Flutter 代码 |
| 一键部署 | Web / iOS / Android 一键发布 |
| 完整代码导出 | 导出干净 Flutter 工程，本地模拟器与真机运行 |
| 托管后端集成 | Firebase、Supabase 等托管后端开箱即用 |
| Git 版本控制 | Pro 档支持版本控制与协作 |

## 定价（积分制）

| 套餐 | 价格 | 说明 |
| --- | --- | --- |
| Free | $0 | 10 积分（一次性），可视化+代码编辑、托管后端、Web 一键部署 |
| Hobby | $20/月 | 100 积分/月，一键部署 App Store/Play Store、完整代码导出 |
| Pro | $90/月 | 500 积分/月，Git 版本控制、优先使用高端模型 |
| Enterprise | 定制 | 专用支持、BYO 模型、SLA、私有云部署 |

注意：积分按操作消耗（生成屏幕、创建功能、导出应用都扣积分），实际成本随迭代频率变化，预算要按积分额度而非裸价规划。

## 调用与兼容性

```bash
# 浏览器使用；Hobby 起可导出完整 Flutter 工程本地运行
flutter run   # 在本地模拟器/真机运行导出的项目
```

- 平台：浏览器（云端工作台）
- 技术栈：Flutter（跨平台移动端 + Web）
- 后端：Firebase / Supabase 托管集成

- 2026 年定价结构：Free / Hobby $20 / Pro $90 / Enterprise 定制。
- PH vibe-coding 分类口碑前列（4.9 分，45+ 评价），被评价为"最快构建移动应用的方式"。
- 免费档积分仅一次性 10 点，仅够浅尝，正式开发需付费档。

## 选型建议

- 目标是移动 App（iOS/Android）且想要 AI 加速 + 能上架：Dreamflow 是当前最直接的路线。
- 纯 Web 应用场景选 Lovable / Bolt.new 更划算；需要 Flutter 生态深度定制再考虑 Dreamflow。
- 对"代码归属"敏感的用户：Hobby 档起提供完整代码导出与本地运行，无锁定。
- 重度迭代用户注意积分消耗速度，先用免费 VP0 设计稿（$0）打底再让 AI 写逻辑，可省积分。
