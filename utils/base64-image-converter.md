图片Base64 转换器帮助您快速完成图片与 Base64 编码的相互转换：

- **图片 → Base64**：上传图片文件，自动生成带 MIME 前缀的 Base64 编码字符串，并显示图片预览
- **Base64 → 图片**：粘贴 Base64 编码字符串（支持带/不带 `data:image/` 前缀），实时预览并一键下载原图
- **支持格式**：JPG、PNG、GIF、WebP、SVG 等常见图片格式
- **一键复制**：点击复制完整 Base64 数据 URI

### 什么是图片 Base64？

图片 Base64 是将图片二进制数据转换为文本格式（Base64 编码）的一种方式。常用于：

- **网页嵌入**：将小图标、背景图直接嵌入 HTML/CSS，减少 HTTP 请求
- **Data URI**：`data:image/png;base64,iVBORw0KGgo...` 格式，可直接在浏览器中显示
- **数据传输**：在 JSON/API 中传输图片数据，避免二进制处理
- **邮件嵌入**：在 HTML 邮件中内嵌图片，不受外部资源加载限制

### 使用场景

- 前端开发中需要将小图标转为 Base64 直接嵌入 CSS
- API 接口需要以 Base64 格式接收/返回图片数据
- 需要快速验证 Base64 编码是否正确
- 将 Base64 编码的图片数据还原为原始文件
