HTTP 接口测试工具支持以下功能：

- **多种方法**：GET、POST、PUT、PATCH、DELETE、HEAD、OPTIONS
- **请求头编辑**：自定义 HTTP 请求头，支持键值对编辑
- **请求体编辑**：支持 JSON、表单数据、URL 编码、纯文本等多种格式
- **响应查看**：状态码、响应时间、响应大小、响应头、响应体
- **JSON 格式化**：自动检测并格式化 JSON 响应
- **Bearer Token**：快捷设置 Authorization 请求头
- **cURL 导出**：一键复制为 cURL 命令
- **历史记录**：自动保存最近 10 条请求记录

适用于 API 开发调试、接口测试、RESTful 服务验证等场景。
